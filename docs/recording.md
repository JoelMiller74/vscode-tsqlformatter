# Recording Demo GIFs

Use these tips to capture short, clear demos showing formatter behavior.

- Tools (Windows):
  - ShareX: free, supports region capture and GIF export.
  - ScreenToGif: free, editor for trimming and text overlays.
- Capture settings:
  - Resolution: 1280x720 or smaller region.
  - Frame rate: 10–15 fps.
  - Duration: 5–12 seconds per feature.
- Tips:
  - Zoom the editor to 120–150% for readability.
  - Show the setting value in VS Code Settings briefly before formatting.
  - Use `samples/sample.sql` and run `Format Document`.
  - Keep the cursor stationary; avoid excessive mouse movement.
- Export:
  - Optimize the GIF (reduce colors, remove duplicate frames).
  - Name files clearly: `commas.gif`, `alias.gif`, `central.gif`.
  - Save into `docs/media/` and they will appear in README placeholders.
